Setup Instructions
Gmail Setup:
  1. Enable 2-Step Verification on your Google account
  2. Generate an App Password for "Mail"
  3. Use your Gmail address as username
  4. Use the App Password as password
GoDaddy / Office 365 Setup:
  1. Sign in to Microsoft 365 Admin Center (admin.microsoft.com)
  2. Go to Users → Active Users → select your user → Mail tab
  3. Click Manage email apps and check Authenticated SMTP, then Save
  4. If MFA is on, generate an App Password at account.microsoft.com → Security → Advanced security → App passwords
  5. Use your full email address as username and your password (or App Password) here
