How It Works

Active templates automatically appear as quick action buttons on each client's detail page.

When you create or activate a template, it becomes instantly available as a one-click email button for all clients.

Template Types & Attachments

Template Type determines which attachments are automatically included:

  • roster_request - Roster Request attachments
  • follow_up - Reminder attachments
  • progress_update - Update attachments
  • quarterly_selections - Selection attachments
  • testing_report - Report attachments
  • custom - No automatic attachments
